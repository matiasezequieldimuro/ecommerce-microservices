# ECOMMERCE BACKEND

# About

This project consists of several services that handle most of the business rules of the e-commerce system.

# Microservice Architechture

Motivated by self learning purpose, the system is decoupled in microservices with single responsability, guaranteeing availability, portability, facilitating maintenance, testing, readability, improving performance and my technical skills. 

# Commits nomenclature

Keywords are used as prefixes to name the commits in such a way that they represent the changes as closely as possible.

- **feature/{...}**: for new functionality or behavior.
- **add/{...}**: to add code into an existing functionality.
- **update/{...}**: to register an update to certain code.
- **modify/{...}**: to register an update to certain code.
- **refactor/{...}**: for changes related to code improvements and optimization.
- **bugfix/{...}**: to resolve small bugs that do not critically affect the program's life cycle.
- **hotfix/{...}**: to resolve critical errors in the productive branch.
